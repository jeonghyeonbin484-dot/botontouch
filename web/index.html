01 · 준비

처음 시작하기

  1. 프로젝트 폴더의 실행하기.cmd를 실행합니다. 처음에는 필요한 구성요소 설치로 시간이 걸릴 수 있습니다.
  2. Chrome 또는 Edge에서 http://127.0.0.1:8765를 엽니다. 사용하는 동안 실행 창을 닫지 마세요. 로그인 화면에서 SAEOLL_ID와 바통터치 비밀번호를 입력하세요. 최초 사용자는 관리자가 전달한 임시 비밀번호를 변경해야 합니다.
  3. 처음 설치하여 계정이 없다면 로그인 화면에서 관리자를 먼저 등록합니다. 관리자는 ‘직원 계정 관리’에서 확인된 SAEOLL_ID로 계정을 발급합니다. 로그인 후 오른쪽 위 새 인수인계를 눌러 업무 묶음을 만듭니다. 업무 묶음은 자료·초안·질문·할 일을 함께 관리하는 공간입니다.
  4. 인수인계 기본 정보에서 업무명·부서·전임자·후임자·기준일을 입력하고 저장합니다. 이미 만든 업무는 위쪽 선택 상자에서 다시 열 수 있습니다.

예시: 업무명은 ‘사무용품 구매 및 관리’처럼 짧게 적으세요. 가상 자료로 먼저 연습하면 흐름을 쉽게 익힐 수 있습니다.

  1. 인수인계서 작성에서 사용할 자료를 체크합니다. 초안에 필요 없는 자료는 선택하지 마세요.

전임자가 검토하고 후임자가 확인하기

직원에게 직접 전달하려면 로그인과 SAEOLL_ID·USER_ID 계정 연결 후 작성 화면의 ‘인수인계 요청하기’를 사용하세요. 부서·직원 선택 → 요청 → 후임자 ‘받은 요청함’ → 수락 또는 보완 → 인계자 최종 완료 순서입니다. 보낸 요청함에서 진행 상태를 확인할 수 있습니다.

  1. 전임자는 초안과 원문을 비교한 뒤 검토 상태를 확인하고 저장합니다.
  2. 검토·인수 확인에서 후임자가 항목별 내용을 확인합니다. 부족한 내용은 보완 의견으로 남기고 전임자가 수정합니다.
  3. 업무를 확정하기 전, 필요한 내용과 후임자의 확인 상태를 점검합니다. AI 결과가 자동으로 검토·인수 완료를 뜻하지는 않습니다.
  4. 인수인계서에서 한글(HWPX) 또는 Word 내려받기 버튼으로 문서를 저장합니다. 특정 확정 버전은 검토 화면의 버전 기록에서도 내려받을 수 있습니다.

다운로드 전 수정 내용을 먼저 저장하세요. 저장된 초안과 현재 업무 묶음의 할 일 등이 문서에 포함됩니다. 실제 한글·Word에서 내용과 페이지 모양을 한 번 더 확인하세요.
