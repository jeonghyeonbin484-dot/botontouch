# 바통터치 심사용 계정 안내 형식

접속 주소: https://botontouch-test.vercel.app

| 구분 | 아이디 | 비밀번호 안내 |
| --- | --- | --- |
| 인계자 | 비공개 계정 안내 파일 참조 | 별도 비공개 파일로 전달 |
| 인수자 | 비공개 계정 안내 파일 참조 | 별도 비공개 파일로 전달 |

현재 상태: 계정 발급과 배포 환경 변경 승인 대기. 위 표는 안내 형식이며 실제 로그인 정보가 아닙니다.

`test-accounts.private.md`는 심사위원에게만 안전하게 전달하고 GitHub·공개 구동안내서에 넣지 않습니다.
심사용 계정은 가상 부서·직원과 연결하고 실제 직원에게 요청할 수 없도록 서버에서 제한한 후 사용합니다.

## 모의자료

`sample-data`의 PDF·XLSX·HWPX 3개는 2027년 드론 안전교육이라는 하나의 가상 업무를 다룹니다.
일정 변경 검토, 미확정 계약, 예산 12,000,000원·집행액 3,200,000원·잔액 8,800,000원이 포함됩니다.
실제 개인정보나 내부 행정자료가 아닙니다.

## 진행 순서

인계자 로그인 → 자료 3개 첨부 → Gemini 초안 → 내용 수정·승인 반영 → AI 예상 질문 확인 → 심사용 인수자 확정·발송 → 인수자 검토·질문 → 인계자 답변 → 인수 수락·최종 완료 → 전체 HWPX 다운로드.

현재 실제 사이트의 로그인·AI·발송·완료 검증은 아직 실행하지 않았습니다. `verification-results.json`의 상태를 확인하세요.
