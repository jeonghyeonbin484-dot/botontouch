# 5단계 작성 흐름 추가 개선 (2026-11-08)

이번 작업의 구현·격리 환경 검증 기록입니다. 후속 AI 대화 화면 개선과 함께 GitHub 저장·Vercel 배포 대상에 포함합니다. 최종 커밋 및 배포 결과는 최종 응답과 해당 커밋의 GitHub 배포 상태에서 확인합니다. 과거 보고서의 실제 운영 계정·Gemini 검증 기록과 구분합니다.

## 변경 영향

- 기존 자료 등록 → AI 초안 → 예상 Q&A → 후임자 지정 → 요청 발송의 순서와 처리기를 재사용합니다.
- `journey_authoring.py`와 `/api/journey/authoring`을 추가했습니다. 업무명은 이전 값이 일치할 때 제목 컬럼만 갱신합니다. 다른 기본정보를 덮어쓰지 않습니다.
- `journey_authoring` 테이블에 사용자·업무·문서별 Q&A 검토 상태, 선택한 후임자, 명시적 확정 여부를 저장합니다. 기존 테이블 삭제·초기화와 자료 이동은 없습니다.
- 검토 상태는 문서 내용과 Q&A 수정 번호에 연결합니다. 문서나 Q&A가 변경되면 다시 검토해야 하며, 다른 문서의 상태를 재사용하지 않습니다.
- 후임자 확정 시 기존 조직도 어댑터와 SAEOLL_ID 검사를 사용합니다. 기존 발송 API의 최신 조직도·본인 여부·문서 지문·출처 변경 검증은 유지합니다.
- 예상 Q&A의 ‘해당 없음’, ‘나중에 처리’를 기존 상태 컬럼과 변경 이력에 저장합니다. ‘해당 없음’은 문서 포함을 해제합니다. 이후 답변 저장으로 다시 답변 완료 처리할 수 있습니다.
- 답변을 본문에 반영할 때 기존 AI 반영안·비교 모달·승인 API를 사용합니다. 승인 전에는 문서가 바뀌지 않으며, 다른 항목을 유지합니다.
- 로그인·직원 계정·조직도/Gemini 설정·HWPX 생성 양식은 변경하지 않았습니다. 실제 서버의 4MB 업로드 한도와 화면 안내를 일치시켰습니다.

## 화면

- 업무명 입력 후 자동저장, 저장 실패 시 입력 유지 및 재시도
- 등록 완료 파일 수와 등록 전·실패 파일 상태, 단계별 완료·미완료 표시
- 초안 항목별 접기·펼치기, AI 생성/직접 수정 표시, 재생성 전 기존 문서 저장 및 확인
- 문서 확인 필요 항목·미답변·나중에 처리 건수 안내, 질문별 처리와 본문 반영안 비교
- 부서 → 부서 내 직원 조회 → 직원 선택 → 후임자 확정 순서
- 최종 확인 목록, 본문 요약 접기, 기존 전체 문서 미리보기·HWPX 다운로드, 발송 전 기존 확인창
- 모든 단계의 임시저장과 진행 위치·검토·후임자 복원
- 작업 영역 확대, 버튼·입력 크기 통일, 중복 안내/조회 버튼 정리, 입력창을 가리는 고정 작업 버튼 제거
- 모바일 답변 반영 모달 내부 스크롤 및 확인 버튼 접근 개선

## 검증

격리된 PostgreSQL 스냅샷 대역과 가상 계정으로 수행했습니다. 실제 운영 자료에 테스트 문서나 요청을 생성하지 않았습니다.

- 서버 회귀 테스트 81개 통과(기존 76개 및 작성 상태 계약 5개)
- 브라우저 테스트 5개 통과: 새 5단계 흐름, 기존 홈/검색/알림, 전체 문서 미리보기, 문장 수정, HWPX 서식
- 새 5단계 흐름은 Edge headless의 1440px·390px에서 각각 실행
- 업무명·문서 저장 503 오류 후 입력 보존 및 재시도, 조직도 조회 오류 후 부서 보존 및 재조회
- Q&A 답변 AI 반영안 승인 시 다른 항목 불변, 해당 없음 상태 저장
- 새로고침 후 진행 단계·검토·확정 후임자 복원
- 최종 미리보기에서 실제 HWPX 다운로드, ZIP 무결성과 수정한 본문 XML 포함 확인
- 발송 확인 취소 후 재발송, 기존 계정 간 수신·수락·완료·접근 권한 회귀 검증
- 제목 동시 수정 충돌, 타 계정 접근, 오래된 문서 지문에 대한 HTTP 403/409 차단
- HTML 번들 빌드, JavaScript 구문, Python 컴파일, Git 공백 검사 통과

화면 캡처: `artifacts/journey-refinement/step-{1..5}-{1440,390}.png`.

## 한계

이번 검증의 AI 응답과 조직도 직원은 격리 환경의 모의 데이터입니다. 실제 Gemini 호출, 내부 조직도 실시간 조회, 운영 계정에서의 발송은 실행하지 않았습니다. HWPX는 다운로드·ZIP/XML 내용을 확인했으며 한컴오피스의 실제 인쇄 배치를 재검증하지 않았습니다.
