# 서식 미리보기와 사용자 매뉴얼

- 왼쪽 사용자 매뉴얼: 14장 목차, 키워드 검색, 이전/다음 장, FAQ 18개, 화면 확대, 인쇄/PDF 저장, 기존 동영상 가이드 연결.
- AI 작성 화면의 문서 아래 및 기존 편집기의 문서 내려받기·복사 → 남양주시 양식 미리보기.
- 원본 `templates/namyangju-report.hwpx`를 실제 한컴오피스로 열어 PDF 저장했습니다. 현재 참고 서식은 1쪽입니다. 비어 있는 원본 영역에 예시 문장을 임의로 채우지 않았습니다.
- PDF는 읽기 전용이고 HWPX는 편집 가능합니다. 화면 배율과 안티앨리어싱에 따른 차이는 있습니다. 별도로 제정된 공식 인수인계서가 아니라 보고서 참고 서식입니다.
- 저장된 실제 인수인계서는 기존 인쇄 미리보기·HWPX 다운로드를 사용합니다. 기존 생성기는 변경하지 않았습니다.
- 서식 변경 시 한컴오피스·pywin32가 설치된 Windows에서 `python tools/build_template_preview.py`로 원본 다운로드본·PDF·해시 매니페스트를 함께 갱신합니다. Vercel에서 변환하지 않습니다.
- 배포 시 `template_preview_assets.py`가 원본/PDF 해시와 다운로드본 일치를 확인합니다. 원본만 교체한 배포는 중단됩니다.
- PDF.js 4.10.38을 자체 정적 파일로 제공하며 라이선스는 `public/media/pdfjs/LICENSE`에 포함했습니다.
- 실제 Chrome·가상 직원·임시 DB로 화면을 촬영했습니다. 캡처의 AI 편집기는 가상 수동 문서이며 실제 Gemini 성공 증거가 아닙니다. 실제 AI 호출 0회.
- 로그인·조직도·AI 처리·DB 스키마·HWPX 생성기 변경 없음.
