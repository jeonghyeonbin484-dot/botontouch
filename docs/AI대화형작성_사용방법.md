# AI 대화로 인수인계서 작성

기존 5단계 작성 화면과 직원 간 대화방은 그대로 사용할 수 있습니다. 새 메뉴 **AI 대화로 작성**은 Gemini와 대화하며 문서를 만드는 별도 작성 도우미입니다.

1. 로그인한 뒤 **AI 대화로 작성 → 새 업무로 시작**을 선택합니다. 기존 문서가 있으면 **현재 문서 이어서 작성**을 선택합니다.
2. **자료 첨부**에서 PDF·HWPX·XLSX·TXT를 선택합니다. 한 번에 5개를 선택할 수 있고 기존 서버의 파일 크기·추출 제한을 적용합니다. Vercel은 파일당 4MB 제한이 있습니다. 이미 추출한 자료는 **등록 자료 선택**으로 연결할 수 있습니다.
3. **인수인계서 작성** 모드에서 원하는 내용을 입력하고 보냅니다. 자료와 최근 대화, 현재 문서를 함께 사용합니다. 아직 읽지 않은 파일을 분석했다고 표시하지 않습니다.
4. 제안된 항목과 **출처 보기**를 확인합니다. 수정하거나 반영할 항목을 선택한 뒤 **선택한 내용을 문서에 반영**을 누릅니다. 이때 실제 문서와 수정 이력이 저장되고 오른쪽 미리보기가 갱신됩니다. 직접 수정해 원문 근거가 불분명해진 문장은 재확인 대상으로 표시합니다.
5. **검토·수정** 모드에서 ‘추진현황을 짧게 써줘’처럼 요청할 수 있습니다. 수정안은 다시 승인해야 저장됩니다.
6. **AI 예상 질문·답변** 모드에서 질문을 생성합니다. **예상 Q&A에 추가하여 검토**한 다음, 확인한 답변을 저장하고 전달할 항목만 선택합니다. 자동으로 최종 문서에 포함하지 않습니다. 실제 후임자의 추가 질문과는 구분됩니다.
7. **남양주시 양식 다운로드**로 기존 HWPX 생성기를 사용합니다. **검토·후임자 지정 및 요청 발송**은 기존 5단계 화면의 Q&A 확인 단계로 연결됩니다. 최종 검토·수신자 선택을 마친 후 직접 발송합니다.

## 저장과 오류

제출한 대화, 선택한 자료, 승인한 문서와 수정 이력은 공유 DB에 저장됩니다. 로그아웃·재로그인 또는 다른 PC에서 본인 대화를 불러올 수 있습니다. 아직 보내지 않은 입력은 공유 DB에 자동 저장하지 않으며 새로고침·탭 닫기 시 경고합니다.

실패하면 입력과 저장 문서를 유지합니다. 실패한 요청은 **이 요청 다시 시도**로 사용자가 다시 보낼 수 있습니다. 같은 요청 식별자의 완료 응답은 재사용하여 중복 Gemini 호출을 방지합니다. 기존 공통 전송 모듈의 60초 제한 및 HTTP 503 제한 재시도 정책은 유지됩니다.

바통터치 자체 한도는 기본적으로 계정당 UTC 날짜 기준 하루 10회이며 실패한 시도도 포함합니다. 화면에 사용 횟수를 표시합니다. Google의 할당량 초과는 별도 안내합니다. 어느 한도도 우회하지 않습니다.

응답은 JSON 전체와 출처를 검증한 후 표시합니다. 현재 토큰 단위 스트리밍은 지원하지 않으며 처리 중 경과 시간과 진행 안내를 표시합니다. 모의 모드에서는 실제 Gemini 분석이 아님을 표시합니다.

## 개인정보 및 권한

기존 서버의 외부 전송 승인 정책과 개인정보 검사, 로그인 검증을 그대로 적용합니다. AI 작성 대화는 생성한 직원 본인만 열람할 수 있으며, 후임자에게는 기존 인수인계 요청 절차로 확정 문서와 선택한 Q&A를 전달합니다. 직원 간 대화방 내용을 자동으로 AI에 보내지 않습니다.
