# 남양주시 양식 HWPX 출력 품질 개선 결과

- 확인일: 2026-11-06
- 배포: https://botontouch-test.vercel.app
- 배포 ID: dpl_78wZ5YGAvRNrx3uUB8QNyS5VrHbu
- 회귀 사례: 사용자가 제공한 종이 없는 회의 및 스마트 회의환경 구축 업무 인수인계서

## 확인한 원인

1. 문서 제목은 실제 업무명이지만 개요의 업무명은 일반적인 업무 묶음명(서무업무)을 사용했습니다.
2. 항목 제목을 다시 본문에 출력해 상위 제목과 중복됐습니다.
3. 혼합 항목명을 그대로 분류해 향후 추진계획이 현안·문제점으로 들어갔습니다.
4. 본문을 요약서에 긴 문단 그대로 재출력했습니다.
5. 예산·물품 키워드만 포함되면 문단 전체를 예산 항목으로 복사해 실제 금액이 없는 설명도 중복됐습니다.
6. 예상 Q&A를 주요 미결사항 안에 삽입했습니다.
7. HWPX에서 출처 번호를 제거하는 과정과 관련 자료 목록 처리가 섞여 본문의 관련 문서 목록이 비고 요약서에만 남기도 했습니다.

## 수정 내용

- 저장된 최종 문서 제목을 기준으로 표제와 개요 업무명을 통일했습니다. 반복되는 인수인계서 접미어와 내부 Markdown 제목·번호를 정리합니다.
- 출력 전용 정리 모듈에서 제목·명시적인 내용 표현을 기준으로 업무, 추진사항, 현안, 미결, 일정·절차 등을 배치합니다. 원문 사실을 생성하거나 다른 항목으로 빈칸을 채우지 않습니다.
- 현재 문제와 이미 분석·해결한 이력을 구분하고, 추진 예정 사항을 진행계획으로 분류합니다. 기대효과를 실제 일정·처리절차처럼 출력하지 않습니다.
- 같은 긴 문단은 본문에 한 번만 출력합니다. 숫자·소수점·부정 표현이 다른 문장은 임의로 합치지 않습니다.
- 요약서는 짧은 절의 발췌와 본문 참조로 구성하며 긴 문단을 재복사하지 않습니다.
- 금액·수량 등 명시된 사실을 확인해 예산·물품에 배치합니다. 추정·검토·문제 분석·비용 회수 효과를 확정된 예산으로 표시하지 않습니다. 추천 Q&A의 금액을 확정 예산으로 승격하지 않습니다.
- 최종 선택된 예상 Q&A만 별도 부록에 출력합니다. 미확인 추천 답변은 확인 필요 표시를 유지합니다. 인수자의 추가 질문은 이력과 함께 보존합니다.
- 실제 등록 자료 메타데이터와 요청 당시의 첨부 목록을 사용해 파일명을 확인하고, 같은 파일의 페이지 위치는 한 줄에 묶습니다. 출처 DB는 삭제하지 않으며 HWPX에 원문 전문이나 출처 번호를 추가하지 않습니다.
- 본문 8개 필수 항목, 마지막 별도 페이지 요약서, 남양주시 양식 글꼴·표·여백·이미지·쪽번호를 유지합니다.

## 회귀 문서 검증

실제 저장된 현재 검토본을 읽기 전용으로 복제해 같은 데이터의 개선 전후 파일을 생성했습니다. 사용자가 첨부한 원본은 별도로 보존했습니다. 첨부 원본은 미검토 상태였지만 현재 저장본은 검토 완료 상태이므로, 페이지 비교는 동일한 현재 저장 데이터를 사용한 개선 전후 문서를 기준으로 했습니다.

| 항목 | 결과 |
|---|---|
| 업무명과 제목 | PASS · 서무업무 대신 실제 업무명 반영 |
| 긴 업무 문단 중복 | 개선 전 5종이 각 2~3회 → 개선 후 반복 없음 |
| 필수 제목·번호 | 본문 1~8 유지 · 내부 제목 중복 제거 |
| 추진 예정과 현안 구분 | 추진·확대 검토 내용을 주요 업무계획으로 분류 |
| 자료 없는 일정·현안·확정 예산 | 확인 필요 표시 |
| 선택 Q&A | 8건 별도 부록 · 미확인 추천 답변 표시 유지 |
| 관련 자료 | 실제 등록 PDF 1건 · 1~3페이지 위치 묶음 |
| 양식·글꼴·표·이미지 | 기존 템플릿 header XML·이미지 바이트 일치 |
| 실제 한글 열기 | 개선 전후 모두 정상 |
| 실제 한글 직접 편집·재저장 | PASS |
| 실제 한글 페이지 배치 | 같은 데이터 6쪽 → 5쪽 · 모든 페이지 확인 |
| 쪽번호 | - 1 - ~ - 5 - 유지 |
| 텍스트 페이지 밖 잘림 | PDF 좌표 검사 및 렌더 화면 확인에서 발견되지 않음 |
| HTML·HWPX 동일 데이터 | 다운로드 지문 일치 · 로컬 API HTTP 200 |
| 실제 Vercel 다운로드 | 가상 계정으로 요청 발송·수신·수락·HWPX 다운로드 PASS |
| 다른 직원 접근 | HTTP 403 유지 |
| 자동 회귀 테스트 | 배포 패키지 111건 통과 · 관련 로컬 테스트 29건 통과 |

각 질문에 필요한 확인 필요 안내와 필수 빈 항목의 확인 필요 표시는 중복 업무 문단 집계에서 제외했습니다. 모든 실제 업무 의미를 새로운 AI로 재작성한 것은 아니며 저장된 최종 내용의 사실을 보존하는 출력 정리입니다. 이번 작업에서 실제 자료를 Gemini에 전송하지 않았습니다.

## 변경 파일

- `report_content.py`: 출력 전용 제목·문단·분류·중복·예산·관련 자료 정리
- `report_document.py`: 공통 출력 모델·짧은 요약·별도 Q&A 부록
- `export_hwpx.py`: 기존 양식으로 Q&A 부록 페이지 생성
- `app.py`: 권한 검사 이후 다운로드에 실제 자료 메타데이터 전달
- `handover_requests.py`: 다운로드에 요청 당시 첨부 메타데이터 전달
- `tests/test_report_quality.py`: 출력 품질 회귀 검사 8건

로그인·비밀번호·조직도·Gemini 호출·대화방 로직은 수정하지 않았습니다. DB 스키마 변경이나 초기화가 없습니다. 변경 전 DB 스냅샷과 출력 코드를 로컬 비공개 폴더에 백업했습니다. 직원 계정 2,832개, 기존 인증정보, 문서·첨부·이력은 유지했습니다. 실제 문서는 GitHub나 공개 정적 파일 경로에 올리지 않았습니다.
