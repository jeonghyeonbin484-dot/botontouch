# 최신 동영상 사용 가이드 (2026-11-08)

- 영상: `/media/botontouch-guide-v2.mp4`
- 포스터: `/media/botontouch-guide-v2.jpg`
- 한국어 자막: `/media/botontouch-guide-v2.vtt`
- 해상도 1920×1080, 길이 240.021초, 파일 크기 11,830,266바이트.
- 최신 실제 Vercel 화면을 Chrome·Playwright로 녹화했습니다. 정지 화면만 이어 붙인 영상이 아닙니다.
- 클릭 위치 강조, 부드러운 확대·축소, 한국어 화면 자막, 로컬 Microsoft Heami 한국어 합성음성, 단계 목차를 포함합니다.
- 네트워크 대기의 빈 화면을 잘라내고 학습하기 쉬운 속도로 편집했습니다. 영상의 응답 속도가 실제 응답 시간을 보장하지는 않습니다.

## 영상 순서
- 0:00 로그인과 홈 화면
- 0:20 AI와 대화로 작성 시작
- 0:50 업무자료 첨부
- 1:20 AI 초안 생성
- 2:05 내용 수정과 문서 반영
- 2:40 후임자 지정과 요청 발송
- 3:20 후임자의 받은 인수인계
- 3:40 전체 HWPX 다운로드

## 실제 동작과 개인정보
최종 영상은 실제 Gemini 초안 생성 HTTP 201 → 사용자 수정·승인 저장 → 가상 후임자 요청 발송·수신 → 실제 전체 HWPX 다운로드를 녹화했습니다. 직원과 업무자료는 모두 가상입니다. 실제 직원에게 요청을 보내지 않았습니다. 테스트 계정·자료는 정리했습니다.

촬영 전체에서 AI 요청은 4회였으며, 최종 채택본은 정상 응답 1회를 사용했습니다. 앞선 촬영 중 정상 HTTP 201을 검증 코드가 잘못 판정한 경우와 메뉴 선택자 문제로 중단한 경우가 있었고, 한 번은 AI 응답 항목 검증에서 HTTP 400으로 거절됐습니다. 실패 화면을 성공으로 대체하거나 모의 응답을 실제 응답으로 표시하지 않았습니다. 기존 AI 코드와 보안정책은 변경하지 않았습니다.

## 메뉴 및 보관
기존 동영상 사용 가이드 메뉴가 새 v2 파일을 재생합니다. 이전 v1 영상은 롤백용으로 보존했습니다. 영상은 Vercel 정적 파일로 제공하며 DB에 저장하거나 함수에서 변환하지 않습니다. 향후 영상 교체 시 `web/video-guide-config.js`의 URL·포스터·자막·목차를 함께 갱신합니다.
