# 바통터치 동영상 사용 가이드

## 시청 방법

1. https://botontouch-test.vercel.app 에 로그인합니다.
2. 왼쪽 **사용 방법 → 동영상 사용 가이드**를 누릅니다. 작은 화면에서는 상단 메뉴 버튼으로 사이드바를 먼저 엽니다.
3. 영상 재생 버튼을 누릅니다. 목차를 누르면 해당 구간부터 재생합니다.
4. 플레이어에서 일시정지, 음량 조절, 전체화면을 사용할 수 있습니다.
5. 기존 **사용자 매뉴얼**도 함께 제공합니다.

영상 직접 보기/저장: https://botontouch-test.vercel.app/media/botontouch-guide-v1.mp4

## 제작 범위

- 실제 Vercel 배포 화면을 Playwright와 Chrome으로 녹화했습니다.
- 가상 계정과 가상 PDF·XLSX·HWPX 자료만 사용했습니다. 실제 직원에게 요청을 발송하지 않았습니다.
- 실제 Gemini 초안 및 예상 Q&A 생성은 각 1회, 합계 2회 실행했고 모두 서버 API HTTP 201로 성공했습니다. 모의 응답을 실제 AI 영상으로 표시하지 않았습니다.
- 가상 후임자가 실제 요청 수신·인수 수락·대화 메시지 발송을 수행했습니다.
- 클릭 위치에 강조 표시를 넣었습니다.
- 1920×1080, H.264 영상·AAC 음성, 약 180.02초, 약 3.4MB MP4입니다.
- 하단 한글 설명 자막과 한국어 로컬 합성 내레이션(Microsoft Heami)을 넣었습니다. 별도 한국어 VTT 자막도 제공합니다.
- 시연 계정 및 자료는 소유 확인 후 정리했으며 기존 직원 비밀번호는 사용하거나 변경하지 않았습니다.

## 정적 영상 제공

영상은 `public/media/`에 저장하며 Vercel 정적 파일 경로로 제공합니다. `/media/`만 기존 API 재작성에서 제외하고 다른 사이트 경로의 인증 흐름은 유지했습니다. Python 함수에는 `public/**`를 포함하지 않아 영상 요청에 DB 연결과 함수 응답 버퍼를 사용하지 않습니다. 실제 구간 요청에서 HTTP 206과 `Accept-Ranges: bytes`를 확인했습니다.

로컬 Python 서버에서는 `guide_media.py`가 공개 안내 영상 파일만 스트리밍하고 Range 요청을 처리합니다. 지정된 안내 영상 파일명 이외 경로는 허용하지 않으며 기존 업무자료를 공개하지 않습니다.

참고: [Vercel 정적 설정](https://vercel.com/docs/project-configuration/vercel-json), [Python 함수 파일 제외 설정](https://vercel.com/docs/functions/runtimes/python)

## 향후 영상 교체

1. 새 MP4를 `public/media/botontouch-guide-v2.mp4`와 같이 새 버전 이름으로 저장합니다.
2. 같은 이름의 표지 JPG와 한국어 VTT 파일을 준비합니다.
3. `web/video-guide-config.js`에서 `url`, `poster`, `captions`, `duration`, `chapters`를 수정합니다. 목차 시작 시간은 초 단위입니다.
4. 영상 준비 전에는 `ready:false`로 두면 빈 플레이어 대신 **준비 중** 안내가 나옵니다.
5. `python web/build.py`로 번들을 생성하고 실제 배포 폴더의 소스·정적 파일을 함께 반영한 뒤 배포합니다.
6. 새 파일 이름을 사용하면 이전 영상 캐시와 충돌하지 않습니다. 파일 이름은 `botontouch-guide-v숫자.mp4/jpg/vtt` 규칙을 따릅니다.
7. MP4는 웹 재생 가능한 H.264/AAC와 faststart를 권장합니다. 교체 후 PC·모바일 재생과 목차 구간 이동을 확인하세요.

## 주요 변경 파일

- `web/shell.html`: 사용 방법 영역의 사용자 매뉴얼·동영상 메뉴
- `web/video-guide.js`: 내부 가이드 페이지·플레이어·목차·준비/오류 안내
- `web/video-guide-config.js`: 영상 주소와 목차를 한 곳에서 관리
- `web/ui.css`, `web/build.py`, `web/index.html`: 반응형 스타일·실제 서비스 번들
- `guide_media.py`, `app.py`: 로컬 공개 안내 영상 전용 경로
- `vercel.json`: 영상의 정적 제공과 함수 묶음 제외
- `public/media/botontouch-guide-v1.mp4`, `.jpg`, `.vtt`: 영상·표지·자막
- `tests/test_video_guide_media.py`: 구간 응답·허용 파일·기존 경로 보존 검사

기존 로그인·비밀번호·조직도·AI·인수인계·채팅 처리 코드는 변경하지 않았습니다. DB 스키마 변경은 없습니다.

## 최종 테스트 결과

배포 패키지 회귀 테스트 103건과 실제 Vercel 플레이어 검증 7항목이 통과했습니다. PC 전체화면, 구간 탐색, 음성 디코딩을 확인했고 모바일은 Chrome 에뮬레이션으로 검증했습니다. 실물 휴대전화·Safari·Edge는 이번에 직접 검증하지 않았습니다.
