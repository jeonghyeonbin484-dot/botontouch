# 직원 로그인 현재 사용 방법

## 최초 로그인

1. https://botontouch-test.vercel.app/login 에 접속합니다.
2. 본인의 새올 ID(SAEOLL_ID)를 입력합니다. 대문자로 입력해도 소문자로 처리합니다.
3. 아직 비밀번호를 설정하지 않은 일반 직원은 초기 비밀번호 `1234!`로 로그인합니다.
4. 최초 비밀번호 설정 화면에서 문자·숫자·기호를 포함한 12~200자의 새 비밀번호를 설정합니다.
5. 설정 완료 후 로그인 화면에서 새 비밀번호로 다시 로그인합니다.
6. 이후에는 변경한 비밀번호만 사용합니다. 변경 전에는 인수인계 자료 등 내부 기능을 이용할 수 없습니다.

관리자 계정과 이미 설정한 비밀번호는 유지됩니다. 비밀번호를 변경한 직원을 조직도 동기화 또는 일괄 발급으로 초기화하지 않습니다. 계정이나 SAEOLL_ID가 없는 직원은 임의로 자동 생성하지 않습니다.

## 적용 상태와 검증

2026-11-06 Supabase 확인: 전체 2,832계정, 관리자 1명은 기존 비밀번호 유지, 일반 직원 2,831명은 최초 비밀번호 설정 대상입니다. 이전에는 일반 직원 전원이 비활성·무작위 비밀번호 상태여서 로그인할 수 없었습니다. DB 백업 후 비밀번호 미설정 일반 직원만 활성화했으며, 개인별 솔트를 가진 Argon2id 해시를 저장했습니다.

실제 Vercel의 일반 직원 계정으로 초기 로그인, 변경 전 내부 API 차단, 비밀번호 설정, 새 비밀번호 재로그인과 메인 화면을 검증했습니다. 시험 계정은 검증 후 초기 설정 대기 상태로 복원했습니다. 실제 직원에게 시험 인수인계 요청이나 AI 외부 전송은 수행하지 않았습니다.

## 서버 정책

`BATON_STAFF_SHARED_INITIAL_ALLOWED=true`를 명시한 서버에서만 요청된 공통 초기 비밀번호 로그인을 허용합니다. 기본값은 false입니다. 이 설정은 비밀번호를 새로 발급하거나 기존 비밀번호를 초기화하지 않습니다. 설정 완료 후에는 공통 초기 비밀번호로 로그인할 수 없습니다.

공통 초기 비밀번호는 직원 본인확인을 대신하지 않습니다. 새올 ID를 아는 다른 사람이 먼저 계정을 설정할 수 있습니다. 이번 설정은 사용자가 해당 위험을 알고 명시적으로 요청한 정책이며, 새올 SSO가 연결된 것은 아닙니다.

## 보존

기존 Supabase 계정·관리자·업무 기록은 유지했습니다. 적용 전 백업은 프로젝트의 `data/private/staff-initial-login/`에 보관하며 공개 저장소와 배포에 포함하지 않습니다. 기존 Neon DB는 수정하거나 삭제하지 않았습니다.
