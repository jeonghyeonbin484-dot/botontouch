# 자료함 개선 및 검증 기록

## 구현

- 업무자료 탭을 파일명·연결 업무·형식·등록일·작업의 표로 표시한다. 모바일에서는 표 내부를 좌우로 스크롤하며 페이지 전체의 가로 넘침을 방지한다.
- 파일 형식, 관리 자료/전달받은 자료, 연결 업무, 검색어, 등록일/수정일/제목 정렬과 기존 페이지 이동을 제공한다. 인수인계 문서·AI 작성 대화 탭은 유지한다.
- PDF는 저장된 원본을 브라우저 PDF 뷰어로 표시하고 추출 본문 보기와 다운로드를 제공한다. HWPX·XLSX·TXT는 기존 추출기를 재사용해 본문과 시트 표를 표시한다. HWPX 원본의 글꼴·레이아웃·이미지, 엑셀 병합·수식·서식은 완전 재현하지 않으며 화면에서 안내한다. XLS·HWP·스캔 PDF OCR 등 기존 미지원 형식을 새로 지원한다고 표시하지 않는다.
- 단일/현재 페이지 선택 자료를 편집 권한이 있는 업무의 기존 인수인계서 또는 본인 AI 대화에 연결하거나 새 AI 대화를 시작한다. 기존 문서 연결은 해당 문서를 연 AI 대화에 참고자료를 붙이는 방식이다. 문서 본문은 자동 변경하지 않으며 기존 AI 제안 승인 절차를 유지한다.
- 전달받은 자료는 현재 수신자에게 허용된 요청의 전달 당시 보존본으로 표시한다. 연결 시 대상 업무에 복사하고 같은 바이너리가 이미 있으면 재사용한다. 원본 요청 및 전달본은 변경하지 않는다.
- 동일 업무에 바이트가 같은 파일을 다시 업로드하면 기존 자료 ID를 반환하고 '기존 자료 재사용'을 표시한다. 파일명만 같은 다른 내용의 파일은 중복으로 취급하지 않는다. 자료 교체는 기존처럼 별도 처리하며 명시적으로 버전을 갱신한다.
- 삭제 전 연결 문서명·건수, AI 대화 수, 전달 요청 수와 영향을 안내한다. 기존의 목록 제외(soft delete) 방식으로 과거 문서의 인용·본문, 전달 파일과 보관 데이터는 유지한다. 삭제 확인 후 자료 버전이 바뀌면 삭제를 거절한다.

## 권한과 저장 구조

파일 본문·원본 다운로드·삭제 영향 조회·재사용·연결 대상 조회를 서버에서 검사한다. 관리 자료는 기존 업무 권한, 전달본은 요청 참여자 권한을 사용한다. 전달받은 원본에 삭제 버튼을 제공하지 않으며 영향 조회도 거절한다. AI 대화의 본인 소유 검사와 편집 권한 검사도 기존 API에서 유지한다.

기존 `documents`, `document_files`, `request_files`, AI 대화 첨부 관계 및 공유 DB 저장 경로를 재사용한다. 스키마 변경이나 데이터 초기화는 수행하지 않는다. 업로더 개인 소유 정보가 없는 기존 자료에는 소유자를 추측하지 않고 '내가 관리하는 자료' 또는 '공유받은 자료 · 읽기 전용'으로 표시한다. 전달본은 별도의 요청별 기록이므로 동일 바이너리라도 서로 다른 전달 요청은 각각 표시된다.

## 검증

- 격리된 가상 직원·공유 저장소에서 37개 회귀 검사를 통과했다. 자료함, AI 저장·승인, 로그인, 공유 DB 장애 처리, 파일 보존·전송, 기존 5단계 작성, 홈 및 메신저를 포함한다.
- 최종 변경 후 자료함 서버·브라우저 5개 검사도 재실행하여 모두 통과했다. PC 1440px 및 모바일 390px에서 PDF 원본/다운로드, HWPX·엑셀 추출 미리보기, 탭 유지, 문서 연결, 전달 자료→기존 AI 대화 연결, 중복 업로드 안내, 삭제 영향/취소, 페이지 넘침을 확인했다.
- 비참여자·미인증자 접근 차단, 타 업무 연결 거절, 삭제 직전 버전 충돌, 원본 삭제 후 전달 파일 보존, 재사용 중복 방지, 재로그인 후 첨부 유지도 검사한다.
- 운영 사용자 자료를 삭제하거나 테스트 자료를 등록하지 않았다. 운영 점검은 공개 로그인 화면·미인증 접근 차단·저장소 준비 상태로 한정한다. 실계정 로그인, Gemini 및 조직도 실호출 검증은 수행하지 않는다.
