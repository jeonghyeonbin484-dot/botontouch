# 저장된 인수인계서 첫 페이지 미리보기

## 구현
AI 작성 화면의 오른쪽만 변경했습니다. 기존 저장 문서의 `/api/drafts/{id}/export.html?view=first-page`를 사용하며, HWPX 생성기의 기존 출력 정리 함수를 공통 함수로 추출해 같은 내용을 렌더링합니다. 기존 HWPX 패키지 내부 파일은 추출 전후 모두 동일함을 확인했습니다.

흰색 A4, 연회색 배경, 원본 로고·띠·회색 항목 제목·문단을 표시합니다. 전체 문서를 HTML로 조판한 다음 첫 페이지만 표시하며, 내용을 임의로 요약하지 않습니다. 패널 너비에 맞춰 비율을 유지해 축소하고 패널 안에서 세로 스크롤합니다. 전체 문서는 기존 HWPX 다운로드로 받습니다.

AI 답변만 생성하면 갱신하지 않고, 사용자가 문서 반영을 승인해 저장된 데이터가 바뀌면 자동 갱신합니다. 문서 선택 변경 시 이전 요청을 취소하고 최신 선택만 표시합니다. 실패 시 저장 내용은 유지하고 다시 불러오기를 제공합니다.

기존 빈 서식 PDF 뷰어는 번들에서 제외했으며 버튼·팝업은 표시하지 않습니다. 원본 HWPX·다운로드 자산과 기존 전체 문서 인쇄 미리보기는 삭제하지 않았습니다. 매뉴얼의 해당 안내도 현재 화면에 맞게 바꿨습니다.

## 변경 파일
- web/studio-document-preview.js: 오른쪽 전용 첫 페이지 렌더링·갱신·요청 경합 방지
- web/build.py, web/index.html: 기존 빈 서식 뷰어 대신 새 모듈 연결
- web/ui.css: 오른쪽 문서 용지·배경·스크롤
- web/user-manual.js: 불필요한 빈 서식 버튼·안내 정리
- export_hwpx.py: 기존 출력 모델 정리 함수를 변경 없이 추출
- report_export.py: 첫 페이지 미리보기만 동일 HWPX 출력 모델 사용

## 차이와 한계
브라우저 HTML 조판이며 실제 HWPX를 실시간 PDF 변환하는 방식은 아닙니다. 공통 내용·서식으로 표시하지만 글꼴 대체와 줄바꿈 때문에 모든 문서에서 한글의 정확한 첫 페이지 경계를 보장할 수 없습니다. 동일한 긴 가상 문서를 실제 한컴오피스로 PDF 저장해 비교했으며, 첫 페이지의 반복 시험 문장 21개는 일치했습니다. PDF 일부 글꼴 추출 경고가 있어 제목까지 정밀 텍스트 대조가 완료된 것으로 주장하지 않습니다.

정확한 페이지 동일성이 필수라면 한컴오피스 변환이 가능한 별도 서버에서 저장 버전별 PDF/이미지를 생성해야 합니다. 현재 Vercel Python 환경에는 한컴오피스가 없으므로 그 변환 서비스를 구현·활성화했다고 표시하지 않습니다.

## 검증
독립 임시 DB·가상 계정·모의 AI로 승인 전후 갱신, 다른 실제 저장 문서 전환, 긴 문서 첫 페이지만 표시, 로고·내용·모바일·전체 HWPX 요약서 유지 검증. 실제 Gemini 호출 없음. 기존 서버 회귀 130건 통과.
