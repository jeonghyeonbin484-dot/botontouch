# AI 대화형 작성 화면 개선

## 변경
- 모델명·실제 AI·일일 사용량 상단 표시 제거. 서버의 API·사용량 제한은 변경하지 않음.
- 현재 문서·대화 선택, 자료 첨부와 자료함 선택, 새 업무 시작, 열어 둔 문서로 대화 시작, 미리보기 버튼을 상단에 통합.
- 상단과 입력창 클립은 같은 기존 업로드 함수와 파일 입력을 사용. 첨부 수와 파일명 표시, 분석 자료 제외 유지.
- 인수인계서 작성이 기본. 기존 일반 대화·Q&A·검토 모드는 입력창에서 선택.
- 신규 대화 안내와 추천 요청 4개 추가. 추천 요청은 입력창에 채우고 사용자가 내용을 보완해 전송.
- Enter 전송, Shift+Enter 줄바꿈. 한글 조합 중 Enter는 전송하지 않음.
- 사용자/AI 메시지 구분, 안전한 텍스트 기반 제목·목록 표시, 이전 대화 추가 조회 시 스크롤 보존.
- 문서에 반영은 기존 사용자 승인 API를 그대로 사용. 자동 반영하지 않음.
- 처리 중 중복 전송 차단, 429 제한 안내, 실패 입력 보존과 수동 재시도 유지.
- 실제 응답에서 기술 정보는 숨기되 모의 응답은 명확히 표시.

## 변경 파일
web/ai-studio.js, web/ui.css, web/index.html. 기존 서버 AI 처리·인증·DB 스키마 변경 없음.

## 검증 범위
독립 임시 DB와 가상 자료로 Chrome에서 두 첨부 버튼·자료 선택·제외·문서 승인 저장·Q&A·재로그인 복구·429 오류 보존·Enter/Shift+Enter·HWPX·모바일을 검증. 실제 Gemini 호출은 수행하지 않고 모의 AI로 UI 회귀 검증.
